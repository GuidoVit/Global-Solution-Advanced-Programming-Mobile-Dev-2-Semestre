StudyMaster - App de Competências
Aplicativo React Native para gerenciar competências e acompanhar sessões de estudo com progresso visual.

Pré-requisitos
Node.js (v16 ou superior)

npm ou yarn

Expo CLI instalado globalmente

Instalação
Clone o repositório:
git clone https://github.com/GuidoVit/Global-Solution-Advanced-Programming-Mobile-Dev-2-Semestre.git
cd StudyMaster

Instale as dependências:
npm install

Executar o Projeto
Inicie o servidor Expo:
npm start

Ou use o comando direto:
expo start
